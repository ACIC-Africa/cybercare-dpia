DejaVu fonts — vendored into PrivacyCare as package data
========================================================

Files in this directory:
  DejaVuSans.ttf        DejaVu Sans, Book   (version 2.37, from Debian
  DejaVuSans-Bold.ttf   DejaVu Sans, Bold    fonts-dejavu-core 2.37-8)

Why these files are in the repository at all: see
fides/api/privacycare/pdf.py's module docstring, point 2. The DPIA PDF is
filed with a regulator; a ReportLab built-in font renders glyphs it lacks
as solid black boxes, and the image this product ships as
(python-slim-bookworm) carries neither fontconfig nor any DejaVu face. The
font a regulator-facing document is set in is therefore part of the
application, not a host dependency.
